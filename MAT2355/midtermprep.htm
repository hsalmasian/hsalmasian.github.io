How to succeed in the midterm exam:

  • The midterm exam is based on all of the material that was covered in class before the study break, i.e., from sections III.1.1 through III.4.5 of the textbook.
  • You should know all of the definitions that are mentioned in class. Some examples of definitions are: Cauchy sequences, supremum of a set of real numbers, infimum of a set of real numbers, accumulation point of a sequence, limsup and liminf, absolute convergence of a series, pointwise convergence and uniform convergence of sequences of functions, uniform continuity, etc.
  • As a reference for definitions, you can use the class notes that have been uploaded on Virtual Campus. In the exam, if you are asked to write a definition, you should write the definition as precisely as possible. Your answer does not have to be "word for word" the same as the one given in the notes. However, your answer should be accurate. If you state a definition vaguely, you will lose points.
  • You should review the assignments and the solutions of the questions solved in the DGD (available on Virtual Campus). Study the posted solutions and compare them to your own solutions. Some of the assignment and DGD questions might appear on the midterm exam.
  • It is a very good idea to work on the Recommended Exercises For Further Practice which are posted on the Syllabus webpage. Although a small number of them are probably too hard to be on the exam, they will test your knowledge and your ablility to use the techniques you have learned in this course.
  • A list of Supplementary Exercises has been posted on Virtual Campus. After you prepare sufficiently by the assignments and practice exercises, you can challenge yourself by trying the supplementary exercises. Some of these questions are more challenging than the practice exercises. Questions about the supplementary exercises will be answered in the DGD on February 29.
  • In the exam, solving some of the questions may require application of some theorems. In your solutions, you should clearly indicate which theorem you are using (by briefly mentioning the statement of the theorem, or by giving its title, e.g., "Bolzano—Weierstrass Theorem").
  • Write all of the necessary details of your proofs. For example, if you need to use induction, do not simply write "it follows by induction". You should explain the details of the induction argument.
  • In the exam, you will be asked to prove two theorems. You should know the proofs of the following list of theorems. Numbers refer to statement numbering in the electronic version of the textbook. For your convenience, I have added a brief description of each statement.

    Theorem III.1.3   (every convergent sequence is bounded.)
    Theorem III.1.8   (only one direction: every convergent sequence is a Cauchy sequence.)
    Lemma III.2.3   (the series a1+a2+... converges if and only if |an+1+...+an+k|<ε for every n sufficiently large and every k≥1.)
    Theorem III.3.3   ( a function f:A→R is continuous at a point a in A if and only if for every sequence x1,x2,... converging to a the sequence f(x1),f(x2),... converges to f(a).)
    Theorem III.3.5   (intermediate value theorem).
    Theorem III.4.2   (if a sequence of continuous functions fn converges uniformly to a function f, then f is also continuous.)

Good luck!
