How to prepare assignments

Assignments should be typewritten and submitted as a PDF file. To prepare your assignments you will need a document processor which possesses tools for typesetting math formulas. There are at least two programs which you can use: OpenOffice and LyX. Both of them are available free of charge.

  • OpenOffice:

    OpenOffice is an open-source office software suite with an easy to use, powerful tool for math formulas. It is the preferred document processor for writing assignments. OpenOffice is available free of charge for Windows, Mac, and Ubuntu. You can download the installer package from OpenOffice.Org.

    Here are some more tips:
    • Prepare your assignment in Open Document format (i.e., with extension .odt) in OpenOffice. Generating the PDF file should be the last thing you do before submission of the assignment because you cannot edit a PDF file.
    • Do not import the PDF file containing the questions into your OpenOffice document. On your assignment you just need to write the solutions (i.e., you do not need to write the questions).
    • To add a math equation (e.g., a system of linear equations, a vector, a matrix, etc.) open the equation editor by selecting Insert -> Object -> Formula from the menu bar. You can now typeset your equation either by using the Formula Elements window, or by typing an appropriate command in the lower segment of the page to generate the desired equation.
    • To edit a formula, right click on it and select Edit.
    • Click here to download a sample document containing a handful of examples which you can use as a template in the preparation of assignments. This file should be opened with OpenOffice.
    • For further instructions, check the software User Guides, especially the guide for Math Objects.
  • LyX:

    LyX is available free of charge for Windows, Mac and Linux. LyX largely functions as a front-end to LaTeX, another very powerful but somewhat more sophisticated typesetting system that is widely used by mathematicians, computer scientists, and physicists. The slides, assignments and exams for this course are prepared using LaTeX.

    Learning LyX takes more time than learning OpenOffice but the LyX output usually looks more elegant.

    Using the above programs to prepare your assignments is not mandatory. You can typeset your assignment using other free packages such as LaTeX, or proprietary software such as Microsoft Word.

How to submit assignments

Assignments must be submitted in PDF format. Other formats are not acceptable. Creating a PDF file of your assignment is the last step before submission. Every assignment should be submitted by 10:00 p.m. on its due date.

  • Both OpenOffice and LyX can generate PDF files. After you are done with writing and editing your assignment, from the menu bar select File -> Export as PDF.
  • You cannot edit a PDF file. Generating the PDF file is the last thing to do before submission of the assignment.

    • Some document processors, such as older versions of Microsoft Word, cannot generate a PDF file. In this case, you can use one of a host of freely available applications which can convert your file format to PDF. One example is PrimoPDF. Using a search engine you can easily find several other applications on the internet.

  • After you generate a PDF file, rename it to SSSSSS-aN.pdf where SSSSSS is your student number and N is the assignment number (1 through 4). For example, if your student number is 123456 and you want to submit the third assignment, then the filename should be 123456-a3.pdf.
  • You can now submit your assignment on Blackboard Learn. Do not submit your assignment via e-mail. The submission instructions are given below, but before reading the instrucions, you are highly recommended to watch this video. To submit your assignment, follow these steps:
    • Before submission, check your PDF file with a viewer (e.g., Adobe Reader) to make sure that the content has not been garbled.
    • Go to the course page on Blackboard Learn.
    • Click on the appropriate assignment tab on the left menu bar (e.g., First Assignment).
    • Scroll down to find the Browse My Cmputer tab. Click on it to select and upload your PDF file.
    • At the bottom of the page, click on the Submit button.
    If you want to resubmit your assignment, you can only do it before it is due. You are allowed a maximum of five submission trials.
  • Sometimes the assignment submission procedure fails because the Blackboard Learn server is not functioning properly. Usually, trying to submit your assignment in a few hours, or using a different web browser is all you need to do. If the problem persists, you should contact the Blackboard Learn staff using the Computer Assistance Request Form.
  • Please note that the deadline for submitting an assignment is 10:00 p.m. on the due date. Late assignments will not be accepted. Do not postpone submission of your assignment until last minute because the Blackboard Learn server can sometimes be down. The above deadline is firm and no exceptions will be made.
